.. _hub-fee:

========
付费说明
========

本站为个人维护的开放服务平台，付费采用 **自助下单 + 管理员审核入账** 的方式：

#. 在「我的费用」选择模块、付费方式与档位（或充值数量），生成 **付款标识码**；
#. 线下转账并在 **转账备注** 中填写该标识码；
#. 上传转账截图（电脑端直接上传，或用手机扫码上传）；
#. 管理员核对无误后入账，**审核通过即生效**，无需再次联系。

入口：`我的费用 <https://hub.saintic.com/fee>`__ （需登录）。各服务页面上的
「开通 / 充值」「买断 / 额度」入口会直接跳到对应模块的锚点，如
``/fee#fee-module-sec``。

.. _hub-fee-free:

免费额度与计费方式
==================

未付费也可以先试用，登录用户比匿名用户额度更高；各模块支持的方式不同，
**价格与档位以后台登记、页面公示为准**：

.. list-table::
   :header-rows: 1
   :widths: 22 20 22 36

   * - 模块
     - 免费额度
     - 支持的付费方式
     - 付费后额度 / 计费
   * - 收录查询（``/sec``）
     - 匿名 5 次/天（按 IP）；登录 20 次/天
     - 包年包月 + 按量付费
     - 包年包月按档位给量（如 100 / 500 / 1000 次每天）；
       按量 ￥0.01/次，按余额，无每日上限
   * - 弹幕库（``/danmu``）
     - 登录 100 次/日
     - 仅买断制
     - 买断后 1000 次/日
   * - 飞书群备份（``/feishu``）
     - 登录可备份 1 个群
     - 仅买断制
     - 按档位给群数（如 10 / 20 个群），群内消息条数不限
   * - IPAM 地址池（``/ipam``）
     - 登录可保存 5 个地址池
     - 仅按量付费
     - 超出免费额度后 ￥1/个地址池，按量扣余额

规则要点：

- **免费额度按北京时间自然日计数，次日 0 点重置**；IPAM 的 5 个地址池是持有额度，
  不是每日次数。
- 收录查询命中缓存不重复计次；使用 ``force`` 强制刷新缓存必会计次。
- 弹幕库的每日额度由 **弹幕服务侧** 执行，买断后新建 / 刷新的 Token 自动获得买断额度。
- IPAM 只对 **创建地址池** 的动作计费：按量扣费后删除地址池不退还已扣费用，
  临时划分、子网分配与查询均免费，接口与额度见 :ref:`hub-ipam` 。

.. _hub-fee-types:

三种付费类型
============

后台按模块登记支持的付费类型，三种类型权益不同：

* **包年包月（prepaid）**：固定有效期，期内按档位额度使用、**不消耗余额**；
  单价是「每月」价格，按下单月份数（每「月」按 31 天计）计算应收金额，
  结束时间在审核通过时自动生成。仍在有效期内不可重复购买，续费会从当前结束时间
  向后延长。
* **按量付费（postpaid）**：先充值余额，每次真实消耗扣减余额，无固定有效期；
  余额不足时对应服务会提示充值。可充值的数量按「单价 × 数量」换算（如 IPAM
  ￥1/个、收录查询 ￥0.01/次），一次充够所需额度即可。
* **买断制（lifetime）**：一次性付费，在本站服务存续期间长期有效，不按次扣费、
  不消耗余额；不可重复买断，也不可换成其他付费类型（包年包月可提前转入买断，
  剩余时段视作放弃；按量付费需余额清零后才能转入）。

模块支持情况：收录查询支持包年包月与按量付费（不含买断）；弹幕库、飞书群备份仅买断制；
IPAM 仅按量付费。不同模块支持的档位不同，档位影响额度（如包年包月名次 1/2/3 对应
100/500/1000 次每天，飞书备份档位对应 10/20 个群）。

.. _hub-fee-flow:

自助下单流程
============

#. **下单**

   在 `我的费用 <https://hub.saintic.com/fee>`__ 的「开通 / 续费」中选择模块与付费方式：

   - 包年包月：选档位与月份数；开始时间可选，留空表示审核通过时开始；
   - 按量付费：填充值数量或金额，页面给出「单价 / 数量 / 合计」；
   - 买断制：选档位。

   提交后生成 **付款标识码**，形如 ``F2610247K3M9``\ （``F`` + 北京日期 + 5 位字符），
   同时生成订单。订单需在 **24 小时内** 完成支付，超时自动过期，可重新下单。

#. **转账并备注标识码**

   打开订单详情页，按「付款指引」展示的收款账号转账（管理员可能同时启用多个渠道，
   任选其一）。**务必在转账备注 / 转账说明中填写付款标识码**，这是对账的主要依据。

#. **上传转账截图**

   订单页「上传转账截图」支持两种方式：

   - **电脑端**：直接选择文件上传；
   - **手机扫码（推荐）**：用手机扫描订单页二维码，从相册选择支付宝 / 微信的转账截图
     上传，无需先把截图传到电脑；上传成功后电脑端页面会自动刷新。

   仅支持 jpg / png / webp，单张不超过 5MB，一张截图不能用于两个订单。截图请包含
   **转账金额**、**转账说明（备注标识码）** 与 **转账单号 / 订单号**：微信可在
   「账单详情」中查看，支付宝需先点「展开更多」再截取含「订单号」的页面。
   截图仅用于本次订单审核，请遮盖与订单无关的敏感信息（如账户余额、其它交易记录）；
   凭证图片在审核终态后保留 7 天即销毁，订单记录仍可查看。

#. **等待审核入账**

   订单状态为「待审核」，管理员在后台核对金额、备注标识码与交易号后入账：
   包年包月 / 买断制直接开通权益，按量付费累加余额。审核通过后状态变为「已入账」，
   权益立即生效；被驳回时可按提示重新上传截图。

.. _hub-fee-order-rule:

订单与购买规则
==============

- 同一用户、同一模块、同一付费类型，**只允许一张在途订单（待支付 / 待审核）**；
  内容一致时复用原订单，避免重复付款。
- 金额、收款账号在 **下单时快照**：模块后续调价不影响已下的订单。
- 包年包月 / 买断制 **未到期不可重复购买**；按量付费余额未清零时不可切换为
  包年包月或买断制。
- 待支付订单可自行 **取消**；已取消 / 已过期订单不产生任何扣费。
- 模块未登记或未定价时页面显示「价格待定」，此时暂无法自助下单，
  **不影响已购用户的正常使用**。

.. _hub-fee-status:

查看付费状态与流水
==================

- **「我的费用」**\ （``/fee``）：各模块当前状态（付费方式、档位、额度用量、
  有效期或余额）、可购买模块与我的订单。
- **个人控制台**\ （``/control``）：「我的付费状态」卡片，汇总各模块付费信息。
- **费用流水**\ （``/fee/logs``）：只显示本人记录，可按模块与类型（充值 / 消费 /
  退款 / 调整）筛选并分页；按量付费每次实际扣减都会有一条消费流水（含备注与
  变动后余额），命中缓存未计次的查询不产生流水。

.. _hub-fee-faq:

常见问题
========

* **付款后多久生效？**
  管理员审核入账后立即生效。包年包月与买断制在入账后即刻可用（收录查询的付费缓存
  最长 15 秒刷新）；按量付费余额即时到账，下次调用即按余额计费。

* **该付多少钱？**
  包年包月 / 买断制由后台登记的档位价决定，下单页直接显示应收金额；按量付费按
  「单价 × 数量」换算，一次充够所需额度即可。实际价格以下单页公示为准，
  本文中的数字仅为说明性示例。

* **续费怎么操作？**
  仍在「我的费用」下单：包年包月从当前结束时间向后延长；按量付费为余额充值，
  可累加；买断制在服务存续期间长期有效，无需续费。

* **能换付费方式吗？**
  按量付费余额清零后可切换为包年包月 / 买断制；包年包月可在有效期内提前转入买断
  （剩余时段视作放弃）；买断制不可更换类型，也不可重复买断。

* **退款 / 发票？**
  费用入账后原则上不予退还，请在购买前确认模块与档位；因违规用途被停用的，按
  :ref:`hub-terms` 处理（一经发现立即停用且不予退款）。如需发票，可在订单审核沟通时
  提出，按税务规定办理代开。
