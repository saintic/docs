========
付费说明
========

本站付费采用 **自助下单 + 管理员审核入账** 的方式。完整说明——付费类型
（包年包月 / 按量付费 / 买断制）、各模块价格与档位、下单与订单规则、
转账截图要求、退款与发票等——统一维护在站点内的付费说明页：

`付费说明 <https://hub.saintic.com/fee/docs>`__

.. note::

   付费相关说明以 https://hub.saintic.com/fee/docs 为唯一权威来源，本文档不再重复
   维护价格与规则；各模块页面只说明 **额度执行方式**，价格、档位与下单流程一律以
   上述页面为准。

模块与付费类型：

- 收录查询（``/sec``）：包年包月 + 按量付费
- 弹幕库（``/danmu``）：买断制
- 飞书群备份（``/feishu``）：买断制
- IPAM 地址池（``/ipam``）：按量付费

付费状态与流水入口（均需登录）：

- `我的费用 <https://hub.saintic.com/fee>`__\ ：各模块付费状态、可购买模块与我的订单；
- `费用流水 <https://hub.saintic.com/fee/logs>`__\ ：本人充值 / 消费 / 退款 / 调整记录；
- `个人控制台 <https://hub.saintic.com/control>`__\ ：「我的付费状态」汇总。
