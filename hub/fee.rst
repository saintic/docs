========
付费说明
========

本站为个人维护的开放服务平台，目前 **没有自助支付入口** ，所有付费采用
「线下联系管理员 + 管理员人工录入」的方式完成。本文说明如何完成一次付费，
以及付费后如何核对自己的付费状态。

.. _hub-fee-flow:

付费流程
========

整体分四步：

#. **获取管理员联系方式**

   先通过下方的 :ref:`联系方式 <hub-fee-contact>` 找到并添加管理员的邮箱 / 微信 / QQ
   （添加时请带上约定的备注字样，便于管理员识别）。具体档位与费用以服务页面公示或与管理员
   沟通为准，文档不直接罗列价格。

#. **发送红包 / 转账**

   与管理员确认付费模块、档位与金额后，按下方的 :ref:`支付方式 <openapi-pay-method>`
   完成付款（支付宝口令红包、支付宝转账、微信 / QQ 转账均可）。管理员录入时会把你的付款
   方式记为对应来源： ``wechat`` / ``alipay`` / ``qq`` / ``cash`` / ``other``。

#. **管理员后台录入**

   管理员收到款项后，在 pcs 费用后台（``/fee/`` 的「录入付费」页签）人工登记：
   你的用户 uid、付费模块、付费类型、档位、金额、生效 / 结束时间、交易号等。
   **录入即生效**，无需你额外操作。

#. **在 OpenHub 控制台查看状态**

   登录后访问 `个人控制台 <https://hub.saintic.com/control/>`__ ，
   在「我的付费状态」卡片中即可看到各模块的付费方式、档位、额度与用量、
   有效期 / 余额、累计充值与消费。若暂无任何记录，页面会提示
   「开通或续费请联系管理员」。

.. _hub-fee-types:

付费类型说明
============

管理员录入时按 pcs 的费用模型登记 **付费类型**，三种类型权益不同：

* **包年包月（prepaid）** ：固定有效期（包月 30 天 / 包年 365 天），期内不限量使用、
  不消耗余额；续费时有效期向后延长（结束时间必须晚于当前结束时间）。
* **按量付费（postpaid）** ：按实际用量扣减余额，无结束时间；余额不足时对应服务会提示充值。
* **买断制（lifetime）** ：一次性付费、终身有效，不可重复买断，也不可换成其他付费类型；
  包年包月可提前转入买断（剩余时段视作放弃），按量付费转入需余额已清零。

各服务支持的类型、档位与档位费用，以服务页面（如收录查询、弹幕、飞书备份）的
「付费模块信息」条及控制台「我的付费状态」显示为准。

.. note::

   付费状态由各服务的付费状态缓存决定，管理员录入后通常几分钟内即在控制台生效；
   若录入后控制台未及时更新，可联系管理员触发同步，或稍后刷新查看。

.. _hub-fee-faq:

常见问题
========

* **付款后多久生效？**
  管理员录入即生效，控制台「我的付费状态」一般几分钟内可见（取决于付费状态缓存刷新）。

* **怎么知道该付多少钱？**
  具体档位与费用以服务页面公示或与管理员沟通为准；付款前请与管理员确认模块、档位、金额。

* **续费怎么操作？**
  同首次流程：联系管理员 → 付款 → 管理员录入。包年包月会自动延长有效期，按量付费累加余额。

* **退款 / 发票？**
  个人服务，一般不提供发票，如有必要请联系时说明。退款与服务禁用规则见 :ref:`hub-terms` ：
  拒绝为违规用途使用，一经发现立即禁用且不予退款。
